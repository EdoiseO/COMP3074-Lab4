# COMP3074 LabEx4 — Customers

Phillip Onofua

Kotlin and Jetpack Compose customer list backed by Room and SQLite. The `customers` entity stores an autogenerated ID, name, age and active status. Add Customer validates the fields before saving. Delete removes the selected customer. A Room Flow refreshes the lazy list automatically, and records remain saved after reopening the app.

Open the project in Android Studio, sync Gradle and run on Android 7.0 (API 24) or newer. Compile SDK 37 and Java 17 or newer are required.

```sh
./gradlew assembleDebug assembleDebugAndroidTest lintDebug --no-daemon
./gradlew connectedDebugAndroidTest --no-daemon
```

Implementation follows the course's COMP3074 Room / Kotlin / Jetpack Compose lab tutorial (Version 3). Instrumentation tests cover Room insert/delete and persistence, input validation, list updates and activity recreation.
